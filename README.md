# Doctor Chatbot

Telegram-бот для платного общения пользователей с экспертами. Проект разделён на
доменный, прикладной, инфраструктурный и Telegram-слои.

## Быстрый запуск

Скопируйте `.env.example` в `.env` и один раз укажите `BOT_TOKEN`. После этого
весь проект — PostgreSQL, миграции и бот — запускается одной командой:

```bash
docker compose up --build -d
```

Проверить состояние и посмотреть логи:

```bash
docker compose ps
docker compose logs -f bot
```

Остановить проект можно командой `docker compose down`. Данные PostgreSQL
сохраняются в Docker volume `postgres_data`.

Без Docker зависимости можно установить командой `uv sync`, затем выполнить:

```bash
uv run alembic upgrade head
uv run python -m main
```

Если таблицы уже были созданы старым `create_tables()`, сначала отметьте базовую
схему, а затем примените усиление платежей:

```bash
uv run alembic stamp 20261005_01
uv run alembic upgrade head
```

Команды бота: `/start`, `/register <телефон>`, `/experts`, `/status`.

## Важные правила бизнес-логики

- Срок подписки отсчитывается с момента подтверждения платежа.
- Повторный callback платежа безопасен; операция провайдера уникальна.
- Возврат платежа отменяет связанную подписку.
- Сообщения сохраняются только при активной подписке на выбранного эксперта.
- Изменения схемы базы выполняются только через Alembic.
