# Баннеры DoctorShop

Установлен комплект «Доктор на связи»: главная заставка в `client_main.png`
и девять заставок в сине-бирюзовом стиле на белом фоне.
Главная заставка используется также при регистрации; `tariff` использует `tariffs`,
а `admin_user` — `admin_main`, если отдельный файл не задан.
Личные фотографии экспертов сохраняют приоритет в их карточках.
Раздел рефералов показывает обложку, а персональный QR-код открывается кнопкой «QR-код».
При превышении лимита подписи к фото (1024 символа) используется текстовый экран.
Промпты и способ генерации: `PROMPTS.md`.

Положите необязательные изображения в эту папку. Поддерживаются `.jpg`, `.jpeg`, `.png`
и `.webp`. Если файла нет, бот автоматически покажет текстовый экран.

Ожидаемые имена:

- `welcome` — регистрация и приветствие;
- `client_main` — главное меню клиента и пользовательская часть владельца;
- `expert_main` — кабинет эксперта;
- `admin_main` — административная панель;
- `experts` — каталог экспертов;
- `tariffs` — список тарифов;
- `tariff` — карточка тарифа;
- `subscriptions` — подписки;
- `consultations` — консультации;
- `referral` — реферальная программа;
- `help` — помощь;
- `expert_profile` — профиль эксперта;
- `admin_user` — административная карточка пользователя.
- `finance` — баланс и статистика эксперта.

Вместо локальных файлов можно задать Telegram `file_id` JSON-объектом в
`BANNER_FILE_IDS`, например `{"client_main":"AgAC..."}`.
